# EventEase — Event Organizer

Manage an event checklist, track tasks, and estimate your event expenses.

## Run in VS Code
1. Extract this ZIP file.
2. Open the extracted `EventEase` folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension and click **Go Live**.

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload the files inside this folder (`index.html`, `style.css`, `script.js`, and `README.md`).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published site link to appear.

## Features
- Event task checklist
- Add custom tasks
- Budget tracker
- Completion dashboard

No Python installation or backend is required. This is a static website prototype built with HTML, CSS and JavaScript.
